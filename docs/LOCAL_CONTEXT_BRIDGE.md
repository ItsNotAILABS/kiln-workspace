# KILN Workspace local context bridge\n\nWorkspace is the user-facing import/inspection surface. KILN swarm owns the local context index and jailed execution. NEXUS owns policy, identity, budgets and context-pack handoff. Never expose local daemon credentials to the browser. Importing GitHub source is not the same as enabling two-way sync; promotion to upstream requires explicit authorization and receipts.\n\nUse KILN swarm/lib/context-fabric.mjs for bounded local retrieval; provide a server-side adapter only after authenticated per-repository access controls are implemented.\n
